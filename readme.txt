在文章內文寫 [[詞彙]] 就自動連到維基百科，並先確認條目是否存在；不存在時以 MediaWiki 風格的紅色連結呈現。

== Description ==

這是已停止維護的 better-wiki-links 的替代品，行為相同但重寫過：

* `[[初音ミク]]` → 連到預設語言（預設為日文）維基百科的該條目。
* `[[en:Vocaloid|ボカロ]]` → 指定語言與顯示文字。
* 連結前會查詢維基百科 API 確認條目存在，避免把讀者送到 404。
* 條目不存在時輸出紅色連結，行為可選：連到搜尋結果、連到條目建立頁、仍連條目網址、或只顯示紅字不連結。
* 查詢結果會快取，且預設走背景批次查詢，**不會**在讀者載入頁面時同步等待維基百科回應。
* 編輯畫面有「Wiki 連結檢查」面板，發佈前就能看到哪些詞彙會變成紅連結。

= 語法 =

* `[[條目]]` — 使用預設語言。
* `[[條目|顯示文字]]` — 自訂連結文字。
* `[[en:Article]]`、`[[zh-tw:條目]]` — 指定語言，代碼需列在設定的「允許的語言前綴」中。
* `\[[條目]]` — 前面加一個反斜線即可跳脫，原樣輸出不轉換。

`<pre>`、`<code>`、`<kbd>`、`<samp>`、`<script>`、`<style>`、`<textarea>` 區塊內，以及既有的 `<a>` 連結內與 HTML 標籤屬性中的 `[[ ]]` 都不會被處理。

= 存在性檢查怎麼運作 =

1. 儲存文章時，外掛會在同步批次上限內立刻查詢並寫入快取，超出的詞彙改排背景查詢。
2. 前台渲染時只讀快取，讀不到的詞彙排入 WP-Cron 背景批次查詢（一次最多 50 個詞彙一個請求），該次仍以一般連結輸出。
3. 下次瀏覽時快取已就緒，狀態即正確。

存在的條目預設快取 30 天，不存在的預設快取 1 天（讓後來被建立的條目較快轉為正常連結）。兩者都可在設定頁調整。

查詢會跟隨維基百科的重新導向，所以 `[[en:wordpress]]` 會直接連到 `WordPress` 這個正式條目。

== Installation ==

1. 把 `moelog-wiki-links` 整個資料夾上傳到 `/wp-content/plugins/`。
2. 在「外掛」頁面啟用。
3. 到「設定 → Wiki Links」調整預設語言等選項。

== Frequently Asked Questions ==

= 為什麼預設是日文維基百科？ =

ACGN 相關條目在日文維基百科最完整。設定頁的「預設語言」是下拉選單，提供日文、中文（繁體）、English 三個選項；要用其他語言就選「自訂代碼…」再填語言代碼（例如 `ko`、`de`、`fr`）。

= 中文的繁簡怎麼處理？ =

`zh-tw`、`zh-hk`、`zh-cn` 等變體會使用 `zh.wikipedia.org` 並以變體路徑輸出，例如 `https://zh.wikipedia.org/zh-tw/WordPress`。

= 會不會拖慢網站？ =

預設的背景模式下，前台完全不發出外部請求，只讀 transient 快取。設定頁另有「即時檢查」模式，會在前台同步查詢，適合流量小或想要立即正確的站台。

= 已經寫好的舊文章要重新處理嗎？ =

不用，`[[ ]]` 是在輸出時即時轉換的，不會改動資料庫裡的文章內容；停用外掛後內容原封不動。

== Hooks ==

* `mwl_should_process` — 過濾是否處理某段內容。
* `mwl_link_html` — 過濾單一連結的 HTML。
* `mwl_allowed_langs` — 過濾允許的語言前綴。
* `mwl_inline_css` — 過濾內嵌樣式，回傳空字串即可自行接手樣式。
* `mwl_metabox_post_types` — 過濾要顯示檢查面板的文章類型。

= 1.0.1 =
* 修正含引號的條目名稱失效：`the_content` 與 `the_excerpt` 改以優先權 9 處理，趕在 `wptexturize` 之前。先前 `[[Assassin's Creed]]` 的引號會被轉成 HTML 實體，導致網址壞掉且永遠查不到條目。
* 修正停用與解除安裝沒有清乾淨背景排程：改用 `wp_unschedule_hook()`。`wp_clear_scheduled_hook()` 以參數比對，清不掉本外掛帶語言與詞彙參數的事件。
* 修正內文中的裸 `<`（例如 `if (a < b)`）會吞掉後面的詞彙。
* 儲存文章時的預熱與編輯面板的重新檢查改為受同步批次上限保護，超出的詞彙改排背景查詢，避免存檔被外部請求拖住。
* 編輯面板改為沿用既有快取，API 失敗或超出額度時不再退回「未檢查」。
* 編輯面板的連結改為指向重新導向解析後的正式條目。
* 快取前綴改為外掛專屬命名，清除快取時不會誤傷其他外掛的資料。
* 關閉存在性檢查時不再標記 `mwl-unchecked`。
